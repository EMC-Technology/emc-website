# 插件化集成架构设计：闭源安全 + 即插即用

> 版本：V1.0 | 日期：2026-04-30
> 依据：开源 RAG（文本全结构化知识系统）+ 闭源 knowledge-infra + UPCM 外脑 Agent
> 目标：在闭源安全的前提下，实现插件化集成，即插即用

---

## 第1章 核心原则

**开源定义接口，闭源实现接口，运行时组装。**

- 开源 RAG 定义"插座"（trait）
- 闭源模块制造"插头"（实现 trait）
- `PluginRegistry` 是"排插"
- `knowledge-runner` 是"电源"
- 插上就通电，拔了也能用默认功能

依赖方向（关键）：

```
开源 RAG ←── 闭源 knowledge-infra（依赖开源的 trait）
开源 RAG ←── 闭源 upcm-agent（依赖开源的 trait）
开源 RAG ←── 闭源 knowledge-runner（组装所有插件）
```

**绝不能反向依赖**——开源 RAG 的 `Cargo.toml` 中永远不出现闭源 crate。

## 第3章 桥接 Trait 定义

在开源 RAG 的 `knowledge-api` crate 中新增 4 个桥接 trait，作为闭源模块的"插座"。

### 3.1 KnowledgeSource — 知识源插件

```rust
// 文件：knowledge-api/src/plugins/knowledge_source.rs

use async_trait::async_trait;
use error_core::Result;
use serde::{Deserialize, Serialize};
use std::pin::Pin;
use tokio_stream::Stream;
use chrono::{DateTime, Utc};

/// 知识源插件 — 闭源模块的"插座"
///
/// 开源默认实现：LocalFileSource（读取本地文件）
/// 闭源增强实现：GitKnowledgeSource（Git 仓库增量索引）
#[async_trait]
pub trait KnowledgeSource: Send + Sync {
    /// 知识源唯一标识
    fn source_id(&self) -> &str;

    /// 获取文档列表
    async fn list_documents(&self) -> Result<Vec<SourceDocument>>;

    /// 获取单个文档内容
    async fn fetch_document(&self, doc_id: &str) -> Result<SourceDocument>;

    /// 监听变更流（增量索引的核心）
    async fn watch_changes(
        &self,
    ) -> Result<Pin<Box<dyn Stream<Item = SourceChange> + Send>>>;

    /// 健康检查
    async fn health_check(&self) -> Result<bool>;
}

/// 知识源文档
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct SourceDocument {
    pub id: String,
    pub title: String,
    pub source_type: String,
    pub content: Vec<u8>,
    pub metadata: serde_json::Value,
    pub hash: String,
    pub updated_at: DateTime<Utc>,
}

/// 知识源变更事件
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct SourceChange {
    pub change_type: ChangeType,
    pub document_id: String,
    pub timestamp: DateTime<Utc>,
    pub metadata: serde_json::Value,
}

/// 变更类型
#[derive(Debug, Clone, Serialize, Deserialize)]
pub enum ChangeType {
    Created,
    Modified,
    Deleted,
}
```

### 3.3 AgentBackend — Agent 后端插件

```rust
// 文件：knowledge-api/src/plugins/agent_backend.rs

use async_trait::async_trait;
use error_core::Result;
use serde::{Deserialize, Serialize};
use std::pin::Pin;
use tokio_stream::Stream;

/// Agent 后端插件 — UPMC 外脑的"插座"
///
/// 开源默认实现：ReActAgentBackend（基础推理-行动循环）
/// 闭源增强实现：UpcmAgentBackend（100x 更强的 UPMC 引擎）
#[async_trait]
pub trait AgentBackend: Send + Sync {
    fn backend_id(&self) -> &str;

    /// 执行任务
    async fn execute(&self, task: &AgentTask) -> Result<AgentResult>;

    /// 流式执行（实时输出）
    async fn execute_stream(
        &self,
        task: &AgentTask,
    ) -> Result<Pin<Box<dyn Stream<Item = AgentChunk> + Send>>>;

    /// 取消正在执行的任务
    async fn cancel(&self, task_id: &str) -> Result<()>;

    /// 获取后端能力描述
    fn capabilities(&self) -> AgentCapabilities;

    /// 健康检查
    async fn health_check(&self) -> Result<bool>;
}

/// Agent 任务
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct AgentTask {
    pub task_id: String,
    pub instruction: String,
    pub context: serde_json::Value,
    pub max_steps: Option<u32>,
    pub tools: Vec<String>,
}

/// Agent 执行结果
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct AgentResult {
    pub task_id: String,
    pub success: bool,
    pub output: String,
    pub steps_taken: u32,
    pub artifacts: Vec<AgentArtifact>,
    pub duration_ms: u64,
}

/// Agent 流式输出块
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct AgentChunk {
    pub task_id: String,
    pub chunk_type: AgentChunkType,
    pub content: String,
}

/// Agent 输出块类型
#[derive(Debug, Clone, Serialize, Deserialize)]
pub enum AgentChunkType {
    Thinking,
    Action,
    Observation,
    FinalAnswer,
    Error,
}

/// Agent 产物
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct AgentArtifact {
    pub artifact_type: String,
    pub name: String,
    pub content: String,
}

/// Agent 能力描述
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct AgentCapabilities {
    pub supports_streaming: bool,
    pub supports_cancellation: bool,
    pub max_context_tokens: usize,
    pub available_tools: Vec<String>,
    pub supports_multi_agent: bool,
    pub supports_human_in_loop: bool,
}
```

## 第4章 插件注册中心

```rust
// 文件：knowledge-api/src/plugins/registry.rs

use std::collections::HashMap;
use std::sync::Arc;
use error_core::Result;

use super::knowledge_source::KnowledgeSource;
use super::quality_gate::QualityGatePlugin;
use super::agent_backend::AgentBackend;
use super::storage_backend::StorageBackend;

/// 插件注册中心 — 运行时组装的核心
///
/// 开源 RAG 提供 Registry 和默认实现。
/// 闭源 runner 在启动时注册闭源插件。
pub struct PluginRegistry {
    knowledge_sources: HashMap<String, Arc<dyn KnowledgeSource>>,
    quality_gates: HashMap<String, Arc<dyn QualityGatePlugin>>,
    agent_backends: HashMap<String, Arc<dyn AgentBackend>>,
    storage_backends: HashMap<String, Arc<dyn StorageBackend>>,
    active_source: Option<String>,
    active_gate: Option<String>,
    active_agent: Option<String>,
    active_storage: Option<String>,
}

impl PluginRegistry {
    pub fn new() -> Self {
        Self {
            knowledge_sources: HashMap::new(),
            quality_gates: HashMap::new(),
            agent_backends: HashMap::new(),
            storage_backends: HashMap::new(),
            active_source: None,
            active_gate: None,
            active_agent: None,
            active_storage: None,
        }
    }

    // --- 注册方法 ---
    pub fn register_source(&mut self, source: Arc<dyn KnowledgeSource>) {
        let id = source.source_id().to_string();
        if self.active_source.is_none() {
            self.active_source = Some(id.clone());
        }
        self.knowledge_sources.insert(id, source);
    }

    pub fn register_gate(&mut self, gate: Arc<dyn QualityGatePlugin>) {
        let id = gate.gate_id().to_string();
        if self.active_gate.is_none() {
            self.active_gate = Some(id.clone());
        }
        self.quality_gates.insert(id, gate);
    }

    pub fn register_agent(&mut self, agent: Arc<dyn AgentBackend>) {
        let id = agent.backend_id().to_string();
        if self.active_agent.is_none() {
            self.active_agent = Some(id.clone());
        }
        self.agent_backends.insert(id, agent);
    }

    pub fn register_storage(&mut self, storage: Arc<dyn StorageBackend>) {
        let id = storage.backend_id().to_string();
        if self.active_storage.is_none() {
            self.active_storage = Some(id.clone());
        }
        self.storage_backends.insert(id, storage);
    }

    // --- 激活方法（切换活跃插件） ---
    pub fn set_active_source(&mut self, id: &str) -> Result<()> {
        if self.knowledge_sources.contains_key(id) {
            self.active_source = Some(id.to_string());
            Ok(())
        } else {
            Err(error_core::helpers::not_found("knowledge_source", id))
        }
    }

    pub fn set_active_agent(&mut self, id: &str) -> Result<()> {
        if self.agent_backends.contains_key(id) {
            self.active_agent = Some(id.to_string());
            Ok(())
        } else {
            Err(error_core::helpers::not_found("agent_backend", id))
        }
    }

    // --- 查询方法 ---
    pub fn active_source(&self) -> Option<&Arc<dyn KnowledgeSource>> {
        self.active_source.as_ref().and_then(|id| self.knowledge_sources.get(id))
    }

    pub fn active_gate(&self) -> Option<&Arc<dyn QualityGatePlugin>> {
        self.active_gate.as_ref().and_then(|id| self.quality_gates.get(id))
    }

    pub fn active_agent(&self) -> Option<&Arc<dyn AgentBackend>> {
        self.active_agent.as_ref().and_then(|id| self.agent_backends.get(id))
    }

    pub fn active_storage(&self) -> Option<&Arc<dyn StorageBackend>> {
        self.active_storage.as_ref().and_then(|id| self.storage_backends.get(id))
    }

    // --- 默认插件 ---
    pub fn with_defaults() -> Self {
        let mut registry = Self::new();
        registry.register_source(Arc::new(crate::plugins::defaults::LocalFileSource::new()));
        registry.register_gate(Arc::new(crate::plugins::defaults::AlwaysPassGate::new()));
        registry.register_agent(Arc::new(crate::plugins::defaults::ReActAgentBackend::new()));
        registry
    }

    // --- 列表方法 ---
    pub fn list_sources(&self) -> Vec<&str> {
        self.knowledge_sources.keys().map(|s| s.as_str()).collect()
    }

    pub fn list_gates(&self) -> Vec<&str> {
        self.quality_gates.keys().map(|s| s.as_str()).collect()
    }

    pub fn list_agents(&self) -> Vec<&str> {
        self.agent_backends.keys().map(|s| s.as_str()).collect()
    }

    pub fn list_storages(&self) -> Vec<&str> {
        self.storage_backends.keys().map(|s| s.as_str()).collect()
    }
}
```

## 第7章 闭源安全三层防线

### 第一层：代码隔离

- 开源 RAG 只定义 trait，不包含任何闭源逻辑
- 闭源模块在独立 crate 中，永远不发布到 GitHub / crates.io
- 闭源 crate 在私有 Git 仓库中

### 第二层：编译隔离

- 开源 RAG 编译时不需要闭源 crate
- 闭源 crate 依赖开源 RAG（单向依赖）
- 只有 `knowledge-runner` 二进制同时依赖两者

### 第三层：分发隔离

- 开源 RAG：源码发布到 GitHub + crates.io
- 闭源模块：只以编译后的二进制 / Docker 镜像分发
- knowledge-runner：编译时 `strip = true` + `lto = "thin"` + `codegen-units = 1`

## 第9章 启动流程

```rust
// knowledge-runner/src/main.rs（闭源二进制）

#[tokio::main]
async fn main() {
    let config = ConfigLoader::from_file("config.toml").await;

    let mut registry = PluginRegistry::with_defaults();

    // 即插即用：根据配置注册闭源插件
    if config.plugins.git_source.enabled {
        let git_source = GitKnowledgeSource::from_config(&config.plugins.git_source)?;
        registry.register_source(Arc::new(git_source));
    }

    if config.plugins.quality_gate.enabled {
        let gate = InfraQualityGate::from_config(&config.plugins.quality_gate)?;
        registry.register_gate(Arc::new(gate));
    }

    if config.plugins.upcm_agent.enabled {
        if config.plugins.upcm_agent.remote {
            let agent = RemoteAgentBackend::connect(
                &config.plugins.upcm_agent.endpoint
            ).await?;
            registry.register_agent(Arc::new(agent));
        } else {
            let agent = UpcmAgentBackend::from_config(&config.plugins.upcm_agent)?;
            registry.register_agent(Arc::new(agent));
        }
    }

    if config.plugins.lightfield.enabled {
        let storage = LightFieldBackend::from_config(&config.plugins.lightfield)?;
        registry.register_storage(Arc::new(storage));
    }

    let rag = RagEngine::builder()
        .plugin_registry(registry)
        .config(config.rag)
        .build()
        .await?;

    let app = build_router(rag);
    axum::serve(listener, app).await?;
}
```

## 附录：集成中心归属

**PluginRegistry 和 4 个桥接 trait 必须放在开源 RAG 项目（文本全结构化知识系统）的 `knowledge-api` crate 中。**

理由：
1. 开源 RAG 必须能独立编译运行——trait 定义在开源侧才能保证这一点
2. 闭源模块实现开源侧的 trait——依赖方向是闭源→开源（单向）
3. 如果 trait 在闭源侧，开源 RAG 无法引用，整个插件化架构不成立
4. knowledge-runner（闭源）只负责组装，不定义接口

归属矩阵：

| 组件 | 归属项目 | 归属 crate | 理由 |
|------|---------|-----------|------|
| 4 个桥接 trait | 开源 RAG | knowledge-api | 接口定义必须在开源侧 |
| PluginRegistry | 开源 RAG | knowledge-api | 注册中心随接口走 |
| 开源默认实现 | 开源 RAG | knowledge-api | 保证独立可运行 |
| RemoteAgentBackend | 开源 RAG | knowledge-api | gRPC 客户端不含闭源逻辑 |
| GitKnowledgeSource | 闭源 infra | knowledge-infra | 闭源实现 |
| InfraQualityGate | 闭源 infra | knowledge-infra | 闭源实现 |
| UpcmAgentBackend | 闭源 UPCM | upcm-agent | 闭源实现 |
| LightFieldBackend | 闭源 | lightfield | 闭源实现 |
| knowledge-runner | 闭源 | knowledge-runner | 组装入口 |
